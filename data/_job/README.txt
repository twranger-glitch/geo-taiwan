README

Dataset: 2010–2024 continuous GNSS dataset for Taiwan 

Description:
This dataset contains daily GNSS position time series, and associated metadata for continuous GNSS stations in Taiwan.

Structure:
- metadata/: station metadata, offsets, and quality metrics
- time_series/: daily GNSS position time series
- documentation/: file_format_description, processing details

Time span:
2010–2024

Reference frame:
ITRF2020

Processing:
Precise Point Positioning (PPP) using GipsyX

Notes:
Raw GNSS observation data are maintained by the respective operating agencies and are not included in this dataset.
